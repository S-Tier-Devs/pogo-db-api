Pogo DB API v1.0

A static JSON API for Pokémon GO data with pre-computed DPS and STAB stats. Updated automatically every 6 hours.

Endpoints

GET /api/pokemon/index.json

Returns a manifest of all available Pokémon with their dex number, name, and ID.

GET /api/pokemon/{dexNr}.json

Returns full data for a specific Pokémon by Pokédex number, including stats, moves, and computed DPS values.

Try It

Enter a Pokédex number to fetch a Pokémon. These calls hit the API directly from your browser.

GET /api/pokemon/25.json 
// Click "Send Request" to see the response

Quick Start

Fetch a single Pokémon (JavaScript)

const response = await fetch("api/pokemon/25.json");
const pikachu = await response.json();

console.log(pikachu.name);           // "Pikachu"
console.log(pikachu.stats.attack);    // 112
console.log(pikachu.quickMoves[0].computed.dps); // DPS value

Get the full index

const response = await fetch("api/pokemon/index.json");
const allPokemon = await response.json();

// allPokemon = [{ dexNr: 1, name: "Bulbasaur", id: "BULBASAUR" }, ...]
console.log(`Total: ${allPokemon.length} Pokémon`);

Find the best DPS quick move for a Pokémon

const response = await fetch("api/pokemon/150.json");
const mewtwo = await response.json();

const bestMove = mewtwo.quickMoves
  .sort((a, b) => b.computed.stabDps - a.computed.stabDps)[0];

console.log(`Best quick move: ${bestMove.name} (${bestMove.computed.stabDps} STAB DPS)`);

Using with cURL

# Get Pikachu
curl http://localhost:3000/api/pokemon/25.json

# Get the full index
curl http://localhost:3000/api/pokemon/index.json

# Pretty-print with jq
curl -s http://localhost:3000/api/pokemon/6.json | jq '.quickMoves[] | {name, dps: .computed.dps, stabDps: .computed.stabDps}'

Response Schema

Pokémon Object

FieldTypeDescription
idstringInternal Pokémon GO identifier
formIdstringForm-specific identifier
dexNrnumberNational Pokédex number
generationnumberGeneration number
namestringEnglish display name
statsobject|null{ stamina, attack, defense }
primaryTypeobject{ type, name }
secondaryTypeobject|null{ type, name } or null
quickMovesMove[]Fast attacks
cinematicMovesMove[]Charged attacks
eliteQuickMovesMove[]Elite TM fast attacks
eliteCinematicMovesMove[]Elite TM charged attacks
assetsobject|null{ image, shinyImage } URLs
evolutionsarrayEvolution paths with candy costs

Move Object

FieldTypeDescription
idstringMove identifier
namestringEnglish display name
powernumberBase damage
energynumberEnergy cost/gain
durationMsnumberAnimation duration in milliseconds
typeobject{ type, name } — move element type
combatobject|nullPvP stats: { energy, power, turns, buffs }
computed.dpsnumberDamage Per Second: power / (durationMs / 1000)
computed.stabDpsnumberSTAB DPS: dps × 1.2 if move type matches Pokémon type

Computed Fields

Every move includes a computed object calculated at build time:

FieldFormulaDescription
dps power / (durationMs / 1000) Raw damage per second for PvE (gym/raid) battles
stabDps dps × 1.2 (if type matches) Same Type Attack Bonus — applied when move type matches the Pokémon's primary or secondary type
